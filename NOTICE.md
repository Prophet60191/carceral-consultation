## Running a copy

The license asks everyone who runs this program for others over a network to
offer them its source code. The app does this on its About page (`/about`),
linked from the join page, the sign-in pages, phones and the account menu.
Set your copy's source code address on the Brand page (Admin › Brand),
especially if you changed the code. See [docs/BRAND.md](docs/BRAND.md).
